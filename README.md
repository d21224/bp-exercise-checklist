# 오늘의 혈압 운동

평일 생활 리듬에 맞춘 모바일 우선 운동·혈압 체크리스트 PWA입니다.

## 기능

- 요일별 운동 루틴과 매일 체크리스트
- 체크 상태 및 주간 달성률 자동 저장
- 아침·저녁 혈압 기록과 가정혈압 기준 안내
- 브라우저 로컬 저장소 사용(서버 전송 없음)
- 홈 화면 설치 및 오프라인 실행 지원

## 로컬 실행

```bash
npm install
npm run serve
```

## 검증

```bash
npm test
npm run test:e2e
node tests/visual-qa.mjs
```

데이터는 사용 중인 브라우저에만 저장되므로 브라우저 데이터 삭제 또는 기기 변경 시 자동 이전되지 않습니다.
